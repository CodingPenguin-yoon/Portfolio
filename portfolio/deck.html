Project 01 · K-Le-PaaS

자연어로 시작하는 클라우드 운영 관문

FastAPI 기반 Backend Hybrid로 GitHub, Kubernetes, NCP, Slack, 모니터링을 연결했습니다. 배포, 롤백, 헬스체크, 자연어 명령 실행이 하나의 백엔드 API 흐름으로 정리됩니다.

문제 kubectl, NCP 콘솔, GitHub Actions, Slack이 분리되어 운영 절차가 사람의 기억에 의존
구현 Gemini 기반 NLP, 명령 이력, Webhook, Kubernetes/NCP 작업, Slack 알림 통합
의미 명령어 중심 운영에서 문맥과 상태를 함께 보는 운영 관문으로 전환
github.com/K-Le-PaaS/backend-hybrid FastAPI · Kubernetes · NCP · Slack · Gemini NLP
Project 02 · Heimdall

Git 브랜치 업데이트를 실행 가능한 프리뷰 환경으로

Heimdall은 GitHub/GitLab 프로젝트를 등록하고, 추적 브랜치 변경을 감지해 Docker 기반 프리뷰 배포, 로그, 히스토리, 릴리즈 이미지, 롤백을 웹 UI에서 관리하는 배포 매니저입니다.

1

Register

프로젝트와 추적 브랜치를 등록

2

Build

Webhook 후 clone/fetch와 Docker 이미지 빌드

3

Preview

컨테이너 실행, URL, 상태, 로그 추적

4

Rollback

릴리즈 이미지와 히스토리 기반 되돌림

제품 관점

push 이후의 결과를 기다리는 구조가 아니라, 개발자가 배포 상태와 되돌림 경로를 직접 확인하는 구조로 바꿨습니다.

github.com/CodingPenguin-yoon/Heimdall FastAPI · React/Vite · Docker · PostgreSQL · Webhook
Project 03 · Gjallar

Proxmox 운영 판단을 승인 가능한 제어 흐름으로

Gjallar는 Proxmox를 source of truth로 두고, DRS Advisor를 중심으로 마이그레이션 추천, 사전 점검, 운영자 승인, Proxmox task 추적, 감사와 reconciliation을 연결합니다.

Observe

Inventory

VM, node, storage, HA, task 상태를 Proxmox에서 읽습니다.

Decide

DRS Advisor

CPU/Memory, policy, risk, route evidence 기반 추천과 pre-check를 만듭니다.

Authorize

Approval Gate

실행은 승인, fresh gate, live evidence, operation lock을 통과한 job에서만 진행합니다.

제품 관점

자동화를 무작정 넓히는 대신, 위험한 mutation을 사람이 믿고 승인할 수 있는 좁은 경로로 제한했습니다.

github.com/CodingPenguin-yoon/Gjallar FastAPI · React · Proxmox API · Alembic · PostgreSQL · Audit
Capability Summary

제가 반복해서 만든 것은 기능이 아니라 운영의 안전한 흐름입니다.

운영 제어 백엔드

REST API, Webhook, 작업 이력, 승인 상태, 외부 시스템 연동을 한 흐름으로 설계합니다.

배포 자동화

Git 이벤트, Docker 빌드, 프리뷰 URL, 로그, 히스토리, 롤백을 추적 가능한 제품 경험으로 만듭니다.

인프라 운영 안전장치

read-only 기준선, pre-check, approval gate, task tracking, audit artifact를 중요하게 둡니다.

사용자 중심 추상화

kubectl, Proxmox, NCP, Slack처럼 흩어진 도구를 사용자가 이해 가능한 문맥으로 묶습니다.

Closing

운영 자동화는 “실행”보다 “검증 가능한 흐름”이 먼저라고 생각합니다.

K-Le-PaaS, Heimdall, Gjallar는 모두 같은 방향을 봅니다. 반복 작업을 줄이되, 상태와 이력, 승인과 되돌림 경로를 남겨 운영자가 실제로 믿고 사용할 수 있는 시스템을 만드는 것입니다.
