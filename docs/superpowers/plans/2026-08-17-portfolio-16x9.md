> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the canonical A4 portfolio with an 11-slide, architecture-led 16:9 portfolio and tagged PDF that faithfully applies the selected ownership-column visual direction.

**Architecture:** Keep `/portfolio`, the existing Astro document route, and the canonical PDF path. **Tech Stack:** Astro 5, TypeScript, CSS, astro-icon with Tabler icons, Playwright, Chromium PDF, Poppler.
